
# College Student Dashboard 🎓

## About the Project
The College Student Dashboard is a responsive web application
designed to display important academic information in one place.

It provides students with a simple interface to view attendance,
subject performance, class schedules, assignments and announcements.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Student welcome section
- Academic statistics cards
- Attendance overview
- Subject-wise performance
- Daily class timetable
- Assignment tracking
- College announcements
- Responsive design
- Interactive sidebar navigation

## Project Structure

College_Student_Dashboard/
- index.html
- style.css
- script.js
- README.md
- screenshots/

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. View the dashboard in your browser.

## Note
The attendance, marks, timetable and assignment details
displayed are sample data for demonstration purposes.
